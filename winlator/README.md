# Winlator — qual baixar

O Winlator é o app que roda programas de Windows no Android (Wine + Box64).
Ele **não está na Play Store** — é um APK que você instala manualmente.

## Download oficial

- Site: **https://winlator.org** (seção Download)
- GitHub (releases): **https://github.com/brunodev85/winlator/releases**

Baixe o **APK mais recente**, copie pro tablet e instale
(permita "instalar de fontes desconhecidas" quando pedir).

## Dica para o Galaxy Tab S10 FE (Exynos / Xclipse)

Comece pelo **Winlator oficial**. Se tiver tela preta, travamento ao abrir, ou
o driver ExynosTools não aparecer, teste um destes **forks** (mesmo passo a passo
do `GUIA.md`, só muda o app):

- **Winlator Bionic** — costuma ir bem em Exynos.
- **Winlator Cmod** — muitas opções de driver/tweak.
- **Winlator Frost** — outra alternativa popular.

> Procure sempre a versão mais recente de cada fork. Guarde o APK baixado
> aqui nesta pasta `winlator/` pra manter o kit portátil.

## Por que não dá pra eu baixar o APK por você

Os APKs ficam em releases do GitHub/sites que mudam de versão com frequência e
exigem aceitar permissões no próprio tablet. Baixe a versão atual no momento da
instalação — assim você pega correções recentes de compatibilidade com Exynos.
